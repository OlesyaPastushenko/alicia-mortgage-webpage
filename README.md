# Alicia Mortgage

Готовый адаптивный статический сайт на английском. Все изображения включены; внешние сервисы и платные зависимости не нужны.

## Посмотреть
Откройте index.html в браузере, либо выполните `python3 -m http.server 3000` в папке проекта и откройте http://localhost:3000.

## Развернуть на Vercel
1. Распакуйте архив.
2. Загрузите содержимое папки alicia-mortgage в новый репозиторий GitHub (index.html должен быть в корне репозитория).
3. В Vercel выберите Add New → Project и импортируйте репозиторий.
4. Framework Preset: Other. Root Directory: корень репозитория. Build Command: пусто. Output Directory: `.`. Install Command: пусто.
5. Нажмите Deploy. Затем можно подключить свой домен через Settings → Domains.

Альтернатива: из папки проекта выполните `npx vercel` и следуйте подсказкам; для production используйте `npx vercel --prod`.

## Подключить обращения
В config.js замените пустую строку contactEmail на свой настоящий рабочий email. Форма откроет письмо в почтовой программе посетителя; отправку подтверждает сам посетитель. Серверной отправки нет. Пока email пустой, сайт честно сообщает об этом и позволяет скачать черновик обращения. Никакие данные не сохраняются и не передаются на сервер.
Для отправки без почтовой программы нужно отдельно подключить обработчик формы (например, серверную функцию Vercel с почтовым провайдером).

## Содержание
- index.html — тексты и разделы;
- styles.css — оформление и мобильная версия;
- config.js — контактный email;
- app.js — подготовка обращения;
- assets/ — оптимизированные WebP, включая предоставленный портрет Олеси;
- vercel.json — настройки заголовков;
- favicon.svg — значок бренда.

## Языки
Переключатель EN / ES / UK в шапке переводит страницу на английский, испанский и украинский без перезагрузки. Выбор сохраняется в localStorage браузера. Тексты формы, черновики сообщений, подписи изображений и метаданные тоже переведены. Переводы в translations.js; переключение в language.js; сообщения формы в app.js.
